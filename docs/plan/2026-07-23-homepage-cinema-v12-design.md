# 首页影片化 v1.2 设计稿：自研水墨 NPR 管线与三大奇观

日期：2026-07-23
状态：设计稿（用户已批准方案与全部关键决策，授权实施期自主决策）
前置：docs/plan/2026-07-10-homepage-cinema-design.md（v1.1.1 现状，十六节）
前置决策记录：本稿由 brainstorming 流程产出，用户逐项确认——
方案 A（自研水墨 NPR 管线 + 三大奇观）；守住纸/墨/水/光世界观纪律，
但 3D 可以进片（只要能翻译成水墨语言）；性能优先（宁可效果收敛，
不可过度要求设备，对齐 Spotify 式"以渲染技术降低设备要求"）；
山水素材采用 AI 生成 + 程序化高度图；水墨与优雅是总体风格。

## 一、定位

在 v1.1 十二幕 3110vh 骨架之上**只动渲染层与 dive 一幕**，把"惊艳"
推到新上限。不加新幕（dive 扩长除外）、不动谷段、不动内容与 i18n。
本轮的技术宣言：水墨渲染不是一组零散特效，而是一条**自研 NPR
（Non-Photorealistic Rendering）管线**——一次投入，多处复用。

### 准入判据（沿用并修订十三/十四节）

1. 纸/墨/水/光世界观纪律不变；每项技术必须翻译成四种物质之一的
   物理行为。
2. **3D 准入**：能翻译成水墨语言的 3D 允许进片（山水本就是最适合
   3D 化的水墨题材）；翻译不出的 3D（科幻场景/硬表面/色散全息）
   仍然不进。
3. **性能优先**：每项效果先给性能预算再动手；设备要求只降不升，
   中端回退链路一寸不动。

## 二、自研水墨 NPR 管线（gl/ink/）

共享 GLSL 材质函数库（shader chunk），全部被各 pass 引用：

| 函数 | 职责 | 物质翻译 |
|---|---|---|
| `heightNormal` | 高度图/深度图 Sobel 中心差分求法线 | 墨与纸的物理起伏 |
| `inkTone` | 连续光照量化为焦/浓/重/淡/清五阶，阶间蓝噪声阈值过渡 | 墨分五色；阈值过渡 = 宣纸洇化边界（非 halftone 网点） |
| `cunStroke` | 沿地形坡度方向的各向异性笔触纹理 | 皴法——山水画山石肌理笔法 |
| `paperGlow` | 厚度图 + wrap lighting 背透光近似 | 迎光透纸 |
| `mistLayer` | 深度雾分层 | 平远留白——山水画的空间法 |

纪律：全部函数确定性（进度纯函数，滚回即倒放）；半分辨率离屏合成；
零新运行时依赖。

## 三、三大奇观

### 3.1 奇观一：dive 穿越升级为「入画 · 千里江山」

现状：2.5D 深度推轨 + 体积光（dolly pass）。升级为真 3D 水墨山水飞越：

1. **墨流坠山**：穿越临界点，画布上的墨经流体场最后一次调用向下
   流淌，在视口下缘堆积成山峦剪影（流体场读 sinkToValley 模式，
   与 opening/dive 既有模式互斥共存）。
2. **山谷飞越**：镜头沿 scroll 驱动的样条路径飞越山谷。地形 =
   AI 生成水墨山水的**亮度推导高度图**（离线 sharp 管线生成），
   单次 draw call 的高度场网格；fragment 内 `inkTone` 远山淡近山
   浓 + `cunStroke` 皴法肌理 + `mistLayer` 山脊间层层留白雾。
   **飞越的就是这幅真画本身**——扎进画里 = 在 AI 画的画里飞，
   叙事自证最强。
3. **雾出白场**：出山谷时雾气渐浓成全白（宣纸白），白场中
   manifesto 章无缝接管——入纸而出纸，比"破入墨色"更有回环。

行程：dive 200vh -> 320vh；总行程 3110vh -> 3230vh。ChapterRail
窗口按纯函数表自动适配。
性能：一个 256x128 网格 + 一个 fragment pass，零 raymarch，fbm
<= 4 octaves，预算约 1ms。中端回退 = 现有 2.5D dolly 原样保留。

### 3.2 奇观二：展墙墨池——真倒影 + 焦散

现状：DOM 假倒影（翻转 + mask 渐隐 + 微模糊）。升级为 GL 水墨面：

- **真倒影**：展墙画作图集在 GL 中垂直镜像重采样，经法向扰动
  （流体场或解析波面）产生真实水波扭曲，随深度衰减——画入水中，
  水动画动。
- **焦散**：水下光经波面折射在地面投出流动光网（迭代式程序化
  焦散，单色白光，强度 <= 0.08 保持克制），随滚动缓慢生灭。
- 展墙 sticky 期间常驻，半分辨率条带区域渲染；pick 时随墨池退去。
- DOM 假倒影保留为中端/静态回退。

### 3.3 奇观三：macro 凝视——笔触 3D 浮雕 + 迎光透纸

现状：取景窗裁切 + 边缘 DOF。升级为物质级凝视：

- **浮雕**：hero 深度图（现役资产）经 `heightNormal` 求法线，
  掠射光角度随滚动缓转——浓墨处墨真的堆起，飞白处露纸纤维。
- **迎光一拍**：驻留段光源移到画后，`paperGlow` 让笔薄处微微
  透光（纸的物质感直接论据：这是纸，不是屏幕）。
- 实现形态：`gl/passes/relief.ts` 为独立小 pass（法线光照 + 透光
  uniforms），在 macro 链内串联于 denoise 之后，成本可忽略；
  三档管线通用性：中端回退保留现有裁切 + DOF。

## 四、交互物理感：光标抚墨

- **指针注入流体场**：stable-fluids 实例新增 pointer 注入（位置/
  速度/压力半径）。序幕墨云与墨池水面两处常驻响应：鼠标划过墨被
  拨开留下涡迹，停手后粘性耗散回稳。
- **墨池涟漪**：光标在展墙段横向移动时，倒影扭曲中心跟随光标，
  焦散光网随之聚散。
- **粒子趋避**：增殖/墨溅粒子对光标温柔斥力（半径 <= 视口 8%，
  只影响途中粒子，不破坏轮廓纪律；沿用微透明粒子叠云教训的
  alpha/size 双键控原则）。
- 降级：touch 无 pointermove 全部静默关闭；注入只在指针移动帧写
  速度场，静止零成本；reduced-motion 不参与。

## 五、镜头签名（post 扩展；落地 v1.0 登记 TODO"速度响应镜头"）

- **速度拖影**：scrollVelocity 喂垂直 smear/折射强度，快滚镜头
  惯性、停稳回弹——全片统一触觉签名。
- **手持呼吸**：低频 Perlin 亚像素机位漂移（<= 1.2px，只对 post
  UV 生效，不动 DOM）。
- **跟焦**：DOF 焦平面在 macro/dive/landscape 段随叙事远近转移；
  焦外模糊 = 水墨晕染式 soft blur（非高斯）。
- **片门微颤**：gate weave < 0.5px，仅最高质量档开启。

## 六、性能预算（硬约束）

- 全部新 pass 半分辨率离屏；焦散/雾只在条带区域渲染。
- 质量档细分：full（全效果）/ high（关焦散 + 片门颤）/ mid（关
  landscape，回退现有 2.5D dolly；交互保留）/ lite（现有中端管线）。
- EMA 降档新增**单项熔断**：单 pass 超时单独关闭而非整档跳变，
  观感损失最小化。
- 验收线不变：桌面 60fps、无 >50ms 长任务、LCP 不劣化、滚回全片
  可倒放（landscape 相机路径是进度纯函数）。

## 七、素材管线（复用 v1 API 生成链路）

- `apps/web/scripts/gen-landscape.cjs`：经产品自身 v1 API
  （gpt-image-2）生成大横幅水墨山水（中景谷道 + 两侧山脊构图，
  适合飞越）；key 经 `G2I_API_KEY` 环境变量传入，不落盘。
- `apps/web/scripts/ingest-landscape.cjs`：白点归一 + 亮度/墨阶
  推导高度图（sharp），输出山水纹理（webp）+ 高度图（灰度 webp/
  png）入 `public/cinema`。
- 新增资产仅 2 件：山水纹理 + 高度图。

## 八、工程结构

以下均位于 `apps/web/src/features/marketing/components/cinema/`：

```
gl/ink/chunks.ts           水墨 NPR 共享 GLSL 库
gl/passes/landscape.ts     山水飞越 pass（网格 + 相机样条纯函数）
gl/passes/pool.ts          墨池倒影 + 焦散 pass
gl/passes/relief.ts        笔触浮雕 + 透光（串联于 macro 链 denoise 之后）
gl/passes/post.ts          扩展：速度拖影/手持/跟焦/片门颤
interaction/pointer.ts     指针注入（流体/粒子/焦散三路分发）
```
另：`apps/web/scripts/gen-landscape.cjs` / `ingest-landscape.cjs`。

- 相机样条、墨阶量化、焦散相位等全部抽纯函数进 vitest（沿用
  cinema-geometry 测试模式）。
- i18n 零新增（无新文案）；ChapterRail 窗口纯函数自动适配。
- 回退阶梯三层各自走查：full 三奇观 / mid 保留现有 dolly + DOM
  假倒影 / static 静态编排不变。

## 九、验收标准

1. turbo typecheck / lint / test / build 全绿；cinema 自测全过
   （新增纯函数用例：样条求值、墨阶量化、焦散相位、高度图推导）。
2. 桌面 60fps；EMA 单项熔断可验证（人为注入慢 pass 单独关闭）。
3. 滚回全片可倒放：墨流坠山逆为山化墨回画布、焦散生灭可逆、
   浮雕光照随滚动逆转。
4. 三层回退走查 + 关键走查截图存档：墨流坠山/谷中/雾出、浮雕
   迎光、墨池焦散 + 光标拨开墨。
5. LCP 不劣化（新资产懒加载，GL bundle 仍动态导入）。

## 十、实施阶段划分（供实施计划展开）

1. 素材管线：gen/ingest landscape + 高度图推导 + 入库走查。
2. 水墨 NPR 管线：gl/ink/chunks + 纯函数单测。
3. landscape pass：网格/相机样条/墨阶着色/皴法/雾 + dive 行程
   扩长与墨流坠山衔接 + manifesto 白场接管。
4. pool pass：真倒影 + 焦散 + 展墙段接线。
5. relief：macro 浮雕 + 迎光。
6. 交互：pointer 注入三路分发。
7. 镜头签名：post 扩展四项。
8. 质量档细分 + 单项熔断 + 三层走查 + 性能核验收口。

每阶段独立 commit；阶段 3、8 结束各做一次完整视觉走查。

### 实施勘误（相对设计稿与计划的偏差与修复）

1. **landscape 透视除法修复**：网格顶点除法原以 vz clamp 防负，
   身后行被钳到近平面涂抹成墙；改 `w = vz` 真实透视除法，
   负 w（身后行）由裁剪剔除；varyings 同步做透视矫正（`edacc51`）。
2. **fallback dollyVisible 0.999**：dive 回退分支（2.5D dolly）
   暗场须撑到墨潮接管，原窗口上界 1.0 在交接点露一帧空场，
   收至 0.999 与 takeover 窗口咬合（`7b52d47`）。
3. **safeAdd 异常隔离**：单 pass init 抛异常不再拖垮整条 pass 链
   （山水/墨池缺素材时其余 pass 照常就位，`7b52d47`）。
4. **fluid 模拟系 y 向上**：pointer 注入坐标须 y 翻转；墨坠
   inkGatherY = 0.1 才是谷底（原写 0.9 是顶部，墨坠向屏顶汇聚，
   `85dff6f`）。
5. **particles smoothstep 正序重写**：GLSL smoothstep 逆序参数
   行为未定义（v0.8.1 已踩过，本次又现），全部改正序 + 1-x 表达。
6. **pool 修正四项**：INK_NOISE 死注入移除（噪声进了未使用的
   通道）；poolAlpha 与可见门分离（渐显不作硬切）；水位带上界
   裁尾修正（推轨尾段水线越出下缘的残带）；mirrorOpacity 加
   hasPass 条件（交接空窗由 DOM 镜像覆盖，`29a8ab5`/`06c4e93`）。
7. **片门微颤移除**：罩层 alpha 自抖 Δ≤0.001 不可感知，纯开销，
   签名收敛为三项（`6e8eb69`）。
8. **scrollVel 量程 0.55 → 2.0**：日常快滚即可见拉丝，原量程
   只在极端甩滚才触发（`6e8eb69`）。
9. **熔断响应式**：单项熔断落地——降档牺牲最贵可选 pass
   （per-pass CPU 耗时 EMA 近似，GPU 异步无法直接计时），升档
   后进先出恢复；熔断状态经 breakerListener → context
   breakerVersion → scene-wall 重渲染，DOM 墨池镜像随熔断/恢复
   切换（本任务）。
